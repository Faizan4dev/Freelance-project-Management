# Freelance Project Management System (FPMS)

A desktop-based freelancing platform built as an academic/personal project.

## Features
- Role-based access (Client, Freelancer, Admin)
- User authentication
- Project posting and assignment
- Progress tracking
- Payment record handling
- Freelancer review and rating system

## Technologies Used
- Python
- Tkinter
- MySQL

## Note
This project was developed for learning and academic purposes.
