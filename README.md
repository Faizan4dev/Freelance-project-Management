# Freelance Project Management System (FPMS)

A desktop-based freelance management platform designed to streamline collaboration between clients, freelancers, and administrators through dedicated role-based workflows.

The project was built with the vision of exploring how localized freelance ecosystems can function in regions where access to international freelancing platforms may be limited.

---

## ✨ Features

- Role-based access system (Client, Freelancer, Admin)
- User authentication & authorization
- Project posting and assignment workflow
- Progress tracking system
- Payment record management
- Freelancer review & rating system
- Admin management portal

---

## 🛠️ Technologies Used

- Python
- Tkinter
- MySQL

---

## 🎯 Project Goal

This project was developed to simulate a structured freelance marketplace environment while strengthening concepts related to desktop application development, database management, user workflows, and system design.

---

## 🚀 Current Status

The system is fully functional and operational, with future improvements planned for UI/UX refinement, scalability, and additional platform features.
